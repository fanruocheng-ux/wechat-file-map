# 微信文件地图

**GPL-3.0 开源 · Windows 免安装单文件** · © 2026 FRC翡冷翠

把散落在微信文件夹里的文件（聊天收发的图片、视频、文档、表格……）建成一个**本地索引**，
像地图一样按日期、类型、文件夹浏览和检索。灵感来自公众号文章里用 Qoder 做的"微信文件搜索神器"（未开源），本工具为其同类实现。

## 启动

**方式一（推荐，可拷给别人）**：直接双击 **微信文件地图.exe**（单文件，约 30MB，无需安装 Python）。
首次启动自动打开浏览器；拷到别的电脑只需拷这一个文件，双击即用（杀毒软件首次可能拦截，点"仍要运行"即可）。

**方式二（开发模式）**：双击 **启动微信文件地图.bat**（需本机装有 Python 3.12 及依赖）。

索引库、缩略图缓存、导出文件都生成在 exe 旁边的 `data\` 目录，索引在重启/拷贝后依然可用。

首次使用：点「管理文件夹」→ 选择你的微信文件目录（常见如
`…\Documents\WeChat Files\wxid_xxx\FileStorage\File`，新版微信 `…\xwechat_files\wxid_xxx\msg\file`；
工具会自动探测微信注册表里的自定义保存位置，一键点选即可），也可以直接选上一层目录，递归扫描。支持添加多个文件夹（每行一个）。

## 只读承诺

- 绝不移动、改名、修改、删除微信原文件；只读取文件名、大小、时间戳，并为图片/视频生成缩略图缓存。
- 所有数据（SQLite 索引、缩略图、导出文件）都存在本程序 `data\` 目录，不上传任何内容。
- 移除"根目录"只清除索引记录，磁盘文件分毫不动。

## 功能对照（文章 10 条需求）

1. 首次启动选择一个或多个微信文件夹，不假设固定目录、不扫全盘。
2. 递归扫描建立索引：文件名/路径/类型/大小/创建时间/修改时间/所在文件夹，实时进度，失败文件记录在「失败记录」。
3. SQLite 本地索引；重启自动载入；重扫只更新新增/修改/删除的文件（增量）。
4. 文件名 + 路径 + 正文（PDF/Word docx/Excel/TXT/MD 等）搜索，结果标注命中来源；提取不了的文件仍可按文件名找到。
5. 组合筛选：关键词、命中范围、类型、根目录、文件夹、大小范围、创建/修改时间，列表与图表同步联动。
6. 日期查询：按年 / 年+月 / 精确到日 / 自定义区间（含结束当天），闰年、月末、跨年均由日历计算保证。
7. 图表：年度趋势、月度趋势、每日热力图、类型分布、文件夹空间占用，点击图元反向筛选列表。
8. 结果列表可排序、分页；详情弹窗支持图片/PDF/视频/音频预览与文本摘要；一键「打开原文件」「复制完整路径」。
9. 「重复与同名」页：MD5 哈希校验完全重复文件（≤100MB）、同名文件分组；结果可导出 CSV（Excel 中文无乱码）与 Markdown。
10. 测试：`test_wxmap.py` 覆盖扫描、增量、只读安全、日期边界（闰年 2-29、跨年、月末、同日多文件）、组合筛选、内容搜索、重复识别、导出。

### 增量更新需求（第二轮）

- 表格视图 / 缩略图网格视图一键切换。
- 图片与视频的本地轻量缩略图（Pillow / OpenCV），滚动懒加载，缓存于 `data\thumb_cache`，不整读原文件。
- 点缩略图 → 大图预览 + 文件详情；详情里「在热力图中定位」按该文件日期反查热力图。

## 性能（46.5 万真实微信文件实测）

- 关键词/文件名搜索走 **FTS5 trigram 索引**：0.02 秒出结果（3 字以上关键词；1-2 字短词退回全表扫描，约 2 秒）。
- 图表聚合单趟扫描 + 整数分桶：1.4 秒。
- 重复文件识别借鉴 Everything 思路做**同尺寸预筛**——大小唯一的文件不可能是完全重复，直接跳过哈希，配合 4 线程并行读盘。
- 扫描/提取在后台低优先级线程进行，期间页面完全可用；中途关掉程序，下次启动自动续跑。

## 已知局限

- 正文提取仅支持文本型 PDF（前 8 页）、.docx、.xlsx/.xlsm/.csv、纯文本类；老 .doc/.ppt、扫描件 PDF 不提取（仍可按文件名/路径搜到）。
- 完全重复校验只对 ≤30MB 且"同尺寸"的文件计算 MD5，更大的文件不参与重复判定。
- 不解析微信聊天记录数据库，不猜测文件来自哪位联系人；只做文件层面的整理。
- "所在文件夹"筛选为包含匹配。
